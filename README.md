# AI Interview Prep Platform

An AI-powered interview preparation tool that helps users practice real interview scenarios using Google Gemini AI and Puppeteer-based automation.

## 🚀 Features

- AI-generated interview questions based on role/domain (powered by Gemini API)
- Real-time interview simulation
- Secure JWT-based authentication with token blacklisting
- Resume/answer upload with drag-and-drop support
- Session-based interview tracking
- Cookie-secure authentication flow

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB (Mongoose)  
**AI Integration:** Google Gemini API  
**Automation:** Puppeteer  
**Auth:** JWT, HTTP-only Cookies
